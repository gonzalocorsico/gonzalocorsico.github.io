Hotel Occupancy Simulator & Revenue Management

Simulator developed in C# that models hotel operations over a year, generating different tourist profiles and analyzing how demand and occupancy affect bookings and revenue.

The system implements Revenue Management, with dynamic pricing based on occupancy level, season, length of stay, and number of guests.

It also simulates availability, room assignment, purchasing behavior, and reservation rejections due to price or lack of capacity.

To obtain more representative results, it runs 35 annual simulations and exports the results to CSV to analyze indicators such as average occupancy, bookings, and revenue.

Technologies

C# · .NET · OOP · Interfaces · Strategy Pattern · Collections · CSV

F1 Pro Multiplayer

Real-time multiplayer racing game where players use their mobile phones as controllers via the gyroscope, while a large screen acts as the race viewer.

The server manages rooms, players, inputs, and race state in real time using Socket.io. Vehicle physics run server-side with Matter.js, including acceleration, braking, steering, grip, drifting, tire wear, ERS, and turbo.

The game features a lobby and room creation system, multiple roles (Controller/TV), circuits, laps, a real-time leaderboard, and haptic feedback for collisions or going off-track.

The visualization uses HTML5 Canvas and renders circuits, vehicles, turbo effects, particles, and race elements entirely through code.

Technologies

TypeScript · Node.js · Express · Socket.io · Matter.js · HTML5 Canvas · JavaScript

Architecture

Real-time client-server · server-side physics · communication via WebSockets · room system
